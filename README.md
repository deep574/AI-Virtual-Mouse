An AI-powered Virtual Mouse system built using Python, OpenCV, and MediaPipe that allows users to control their computer using hand gestures in real time.

---

#  Features

Hand Tracking using AI  
 Smooth Cursor Movement  
 Left Click Gesture  
 Right Click Gesture  
 Drag & Drop  
 Scroll Up / Down  
 Screenshot Capture  
 Volume Control  
 FPS Counter  
 Real-Time Gesture Detection  
 Modern Gesture UI Popup  

---

#  Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- Computer Vision
- AI Hand Tracking

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/deep574/AI-Virtual-Mouse.git
```

## 2️⃣ Open Project Folder

```bash
cd AI-Virtual-Mouse
```

## 3️⃣ Install Requirements

```bash
pip install opencv-python mediapipe pyautogui
```

## 4️⃣ Run Project

```bash
python main.py
```

# ✋ Supported Gestures

| Gesture | Action |
|---|---|
| Index Finger Move | Cursor Movement |
| Thumb + Index | Left Click |
| Thumb + Middle | Right Click |
| Pinch Hold | Drag |
| Two Fingers Move | Scroll |
| V Gesture | Screenshot |
| Hand Distance | Volume Control |
| Open Palm | Pause |
